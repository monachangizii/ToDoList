# 📝 To-Do List

A clean and functional **To-Do List** program created using **Python (PyQt5)**.
The program allows users to add, edit, prioritize, and delete daily tasks using a simple and streamlined interface.

---

## ✨ Features
- Add new tasks with own **priority levels** (Low, Medium, High).
- Mark a task as **completed** using a checkbox.
- Completed tasks are displayed with **strikethrough** and greyed out.  
- Delete tasks directly from the interface.  
- Scrollable task list with a modern UI.  
- UI designed using **Qt Designer (`todo.ui`)** for easy modification.  

---

## 📦 Tech Stack  
- **Python 3.12**  
- **PyQt5** (UI and widgets)  
- **Qt Designer** (UI layout design)
